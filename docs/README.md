# Документация

Правила разработки — в [CLAUDE.md](../CLAUDE.md) (по строке на правило) и
полными текстами в [.claude/rules/](../.claude/rules/); карта кода и гейтов —
[ARCHITECTURE.md](ARCHITECTURE.md). Здесь всё остальное. Как писать и читать
документы, чтобы агент не перечитывал репозиторий, — [.claude/rules/docs.md](../.claude/rules/docs.md).

Операционный бриф канала «Здоровый Взрослый» (`HEALTHY_ADULT.md`) намеренно
оставлен в корне: на него по имени файла ссылается код бота и админ-UI.

## Что осталось открытым

разложен по областям, чтобы агент читал только свою (раньше это был один
раздел на 200 КБ). Запись ищут `grep -rn '<ключ>' docs/open/`; новая — в файл
своей области, в том же PR, где нашлась (правило №26).
