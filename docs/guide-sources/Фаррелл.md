Файл: `Фарелл Д., Рейсс Н. Шоу А. - Клиническое руководство по схема терапии.pdf` (рус. издание «Научный мир»; скан без текстового слоя — читать через OCR; страница PDF = страница книги + 21). Статус: карта согласована (решения приняты агентом, 2026-11-22), в работе: пачки 1 — #1558, 2 — #1582, 3 — #1595, 4 — #1598, 5 — #1557, 6 — #1581, 7 — #1602, 8 — #1599.

В карте 177 строк: 124 «да», 52 «пропустить» (из них 32 «уже взято»), 1 «отложено: новая тема». Книга — программа групповой схема-терапии при ПРЛ; главное новое — механика группы и приёмы по режимам из сессий осознания, управления и экспериенциальной работы.

## Главное из ещё не взятого

- **Механика группы** (гл. 2.3, 3, 4.1): роли двух терапевтов и право второго остановить работу, «никто не только смотрит», подготовка к группе (уход как копинг, первые ~6 сессий не решать об уходе), ответ на пропуск по его причине, открытые группы с ролью «старшего». В справочнике о группе две записи по Кембриджу.
- **Ведение группы** (гл. 4.1–4.5): сначала актуальный режим группы, потом план; не держать молчание и делать замер режима; «перекличка безопасности»; медиация и групповая эмпатическая конфронтация; «намерение ≠ последствие»; деление времени.
- **Новые техники**: план управления режимами (`mode_management_plan`: на каждый режим приёмы «выйти сейчас» и «ослабить надолго» с привязкой к схеме), план Здорового Взрослого (`healthy_adult_plan`), пузырь безопасности (`safety_bubble`).
- **Копинговые режимы** (гл. 4.5, 5.2): копинг — «бей, беги, замри», его оставляют в запасе на настоящую опасность, а лечат чрезмерность; первым берут самый частый и самый опасный режим; эксперименты со шкалой силы режима; не ослаблять копинг, пока клиент живёт в опасной среде.
- **Приёмы по режимам**: эксперимент с наказанием и чучело Критика как монстра, грустный и тревожный Уязвимый Ребёнок с разными ответами, безопасные игры для гнева с ролью болельщиков, смакование радости в образе и «какой режим перебил радость» для Счастливого Ребёнка.

## Решение (2026-11-22)

Решено агентом по поручению владельца («все решения по справочнику на дирижёре»), мерило — польза практикующему терапевту. Значения колонки «Решение владельца»: «да · пачка N» — писать в пачке N; «пропустить» — уже взято, повтор внутри книги или не про кабинет (оглавления раздаточных материалов, стационар, длинные сценарии); «отложено: новая тема» — в пачки не входит.

Ограничения для пачек:

- Авторское право: текст — пересказ своими словами со ссылкой `[Фаррелл, гл. N]` или `[Фаррелл, 5.4.1]`; без сценариев-диалогов, без пунктов раздаточных материалов, без таблиц строка в строку.
- Голос: обращение к клиенту — в обеих формах через `tr('ты', 'вы')`, род нейтральный.
- Групповые упражнения пишутся в `practiceGroup.ts` (group_therapy, group_techniques или новые записи рядом), а не в записи режимов, если упражнение не перенесено в индивидуальную работу.
- Новая техника — id в `techniqueIds.ts` и знак; новая запись «Для терапевта» — по образцу соседних.
- Строки одной записи из разных глав пишутся одной правкой; повтор между строками сводится, а не дублируется.
- Номера страниц в карте посчитаны разными способами: страница книги = номер файла pNNN минус 21; при расхождении сверять по PDF.
