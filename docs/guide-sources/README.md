# Полка справочника: какие книги кормят какой запрос

Статус темы — в каталоге `shared/src/schemaTherapy/kb/catalogConcerns.ts` (источник правды); таблица ниже — где в картах `docs/guide-sources/` лежит материал. Тема `planned` — обычная пачка «запрос: <id>» в картах, её пишет агент по чек-листу «Новый запрос» (`.claude/rules/knowledge-base.md`).

| Запрос (id) | Статус в каталоге | Книга → главы → пачка карты | Чего не хватает |
|---|---|---|---|
| ПРЛ (`bpd`) | written | Арнц-ПРЛ — вся книга (сделано); Фаррелл и Фаррелл-Шоу — групповая программа (сделано); Янг гл. 9 → пачка 13 (досбор); Кембридж гл. 2 → пачки 18, 19 (профили); Арнтц ПРЛ досбор гл. 1–5 → пачка 14 (сделано) | досбор по Янгу гл. 9: модель из пяти режимов, происхождение, критерии, кризисы |
| Нарциссизм (`narcissism`) | written | Бехари пачки 1–6 и досбор 7 (сделано); Янг гл. 10 (строки ушли в карту Бехари) | — |
| Депрессия (`depression`) | written | Кембридж гл. 13 (минимальная статья, сделано); Арнтц-Якоб 2.3.9 → пачка 3 (сделано #1663); Арнтц ПРЛ гл. 3 → пачка 14 (запрос) | досбор — по новой книге |
| Тревожные расстройства (`anxiety`) | planned | Кембридж гл. 3 табл. 3.2, гл. 13 → пачка 13; Рафаэли гл. 6 → пачка 11; Арнтц ПРЛ гл. 3 → пачка 14 (запрос); Бехари гл. 2 (сцена с начальником) → пачка запроса | статьи нет |
| ОКР (`ocd`) | planned | Кембридж гл. 13 (бокс 13.3) → пачка 14; Арнтц-Якоб 2.3.9 «ОКР» (сделано #1665, режим) | статьи нет |
| Расстройство адаптации (`adjustment_disorder`) | planned | Кембридж гл. 13 → пачка 15 | статьи нет; один раздел книги |
| ПТСР и комплексная травма (`ptsd`) | planned | Кембридж гл. 14 → пачка 16 (частично сделано #1465, #1482, #1489); Хис-Стартап гл. 7 (карта травмы, рескриптинг; строки «да»); Арнтц ПРЛ гл. 5 → пачка 14 (запрос) | статьи запроса нет; порядок воспоминаний и блок из 12 сессий — из Хис гл. 7 |
| РПП (`eating_disorders`) | planned | Кембридж гл. 15 → пачка 17; Хис-Стартап гл. 18 → пачка 12; Арнтц-Якоб 2.3.9 → пачка 12; Дети гл. 8 → пачка 16; Арнтц ПРЛ гл. 1–2 → пачка 14 (запрос) | статьи нет; модель SPEAKS авторская |
| Кластер C (`cluster_c`) | written | Арнтц-Якоб 2.3.4–2.3.6 и упоминания в гл. 1, 2.4, 5.4.4, 6.1.5, 6.3.2, 7.5, 8.2.2 → пачка 15 (сделано #1690); Кембридж гл. 2, 11 → пачка 18 (досбор); Янг гл. 1 → пачка 14 (досбор); Бехари гл. 3 (ассистентка при Покорности) → досбор при случае | программы лечения по шагам у Арнтц–Якоб нет: статья собрана из профилей, двух случаев и упоминаний; досбор — Кембридж гл. 11 |
| Другие РЛ (`other_personality_disorders`) | written | Арнтц-Якоб 2.3.3, 2.3.7, 2.4, 3.2 → пачка 16 (сделано #1690); Кембридж гл. 2 → пачка 19 (досбор); Рафаэли гл. 26 → пачка 12 (досбор); Янг гл. 1 → пачка 15 (досбор) | статья — только истерическое и параноидное; антисоциальное у Арнтц–Якоб есть лишь в судебной модели 2.3.8 (вне рамок), ждёт досбора |
| Паттерны в отношениях (`relationship_patterns`) | planned | Пары гл. 3–4 → пачка 15; Редигер (генограмма, выбор партнёра); Арнтц ПРЛ гл. 5 → пачка 14 (запрос); Бехари гл. 2–4, 8 (кластеры, «старые туфли», родитель-нарцисс) → пачка запроса | «химия схем» — Young, Klosko «Reinventing Your Life» (на полке нет) |
| Работа с парами (`couples`) | planned | Пары пачки 1–4 (основа); Хис-Стартап гл. 13 → пачка 11; Рафаэли гл. 27 → пачка 13; Редигер гл. 14 → пачка 15; Бехари гл. 6–7 (измена, тайм-аут, круг пары), гл. 4 (тексты) → пачка запроса | статья по Парам ещё не написана; остальное — досборы |
| Дети и подростки (`adolescents`) | written | Дети пачка 1 (ядро, сделано #1698); пачки 2–3, 9–14 | оценка, форматы, родители — пачки 2–3 |
| Родитель и младенец (`infant_regulation`) | planned | Дети гл. 4 → пачка 15 | статьи нет |
| Зависимости (`addictions`) | needs_source | Пары гл. 10 (алкоголь в паре, в `couples`); Редигер гл. 13 (отложено); Рафаэли гл. 11 (мост); Арнтц ПРЛ гл. 2, 4 → пачка 14 (запрос); Бехари гл. 1, 6–7 (Отстранённый Самоутешитель) → пачка запроса | книга Болла (двойной фокус): по полке — три небольших раздела |
| Хронические и соматические жалобы (`chronic_somatic`) | needs_source | строк в картах нет | книга по теме не подобрана |
| Судебная модель (`forensic`) | out_of_scope | Кембридж гл. 16 вычеркнута; Арнтц-Якоб 2.3.8 пропущена; Арнтц ПРЛ гл. 2 → пачка 14 (запрос) | решение владельца: вне рамок онлайн-практики |

Книги доступны только на Mac владельца, кроме Арнтц–Якоб (PDF в Google Drive) — облачная сессия может писать запросы только по ней.
