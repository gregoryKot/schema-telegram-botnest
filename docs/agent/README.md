# Харнесс агентов: как с ним работать

Короткая памятка владельцу и агентам. Устройство — раздел «Харнесс агентов» в
[docs/ARCHITECTURE.md](../ARCHITECTURE.md); правила документации —
[.claude/rules/docs.md](../../.claude/rules/docs.md).

## Владельцу: пять привычек, которые экономят больше всего

1. **Размытая задача — начни с `/grill-me`.** Агент задаст вопросы раундами,
   у каждого своя рекомендация; «да» — согласие. Итог — ТЗ в issue. Одна
   переделка стоит дороже всего допроса.
2. **Новая задача — новая сессия.** Хвост прошлой задачи в контексте
   оплачивается на каждом шаге новой. Продолжение длинной работы в новой
   сессии — через `/handoff`: агент оставит записку в issue или PR.
3. **Называй экраны так, как они называются в интерфейсе** («Мой путь», «Что
   это было»). Слово есть в словаре `docs/architecture/glossary.md` — агент
   сразу идёт в нужный файл. Нового слова там нет — агент допишет его.
4. **После крупной задачи — `/retro`.** Агент посмотрит замер (какие вызовы
   съели контекст) и поправит карту, правила или гейт, чтобы следующий потратил
   меньше. Раз в месяц — `/retro журнал`.
5. **Окружение облачных сессий с готовыми зависимостями.** Сейчас каждая
   сессия, которой нужны тесты, сама ставит `node_modules` — минуты и длинный
   вывод. В настройках окружения (меню окружения в заголовке сессии → Edit →
   Setup script) добавь:

   ```bash
   npm ci --silent && npx prisma generate > /dev/null
   ```

   `npm ci` без `--ignore-scripts`: шаг `prepare` ставит merge-драйверы
   бейслайнов (правило №13).

## Агенту: где что

| Нужно | Где |
|---|---|
| Где живёт экран, фича, слово владельца | `docs/architecture/glossary.md`, затем субагент `scout` |
| Куда идти по типу задачи | «Куда идти по задаче» в `docs/ARCHITECTURE.md` |
| Что ловит красный гейт | `docs/architecture/gates.md`; разбор лога — субагент `ci-doctor` |
| Проверить дифф по правилам перед PR | субагент `rules-reviewer` |
| Сколько контекста съела сессия | `node scripts/agent/session-report.mjs` (журнал пишет хук) |
| Карта промолчала | строка в карте + строка в [NAV_LOG.md](NAV_LOG.md) |
