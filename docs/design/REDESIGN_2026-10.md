## Overview
Визуальный редизайн веб-приложения (`webapp/`) репозитория `gregoryKot/schema-telegram-botnest`. Цель — убрать монотонность («однообразно, глаз не цепляется»): ввести тёмный сайдбар, цветовое кодирование по доменам схем, разные типы блоков вместо одинаковых полей, выделение главного действия на каждом экране. Структура, роуты, API и копирайт — без изменений, кроме отмеченных мест.

Охват:
- Кабинет терапевта: Сегодня, Все клиенты, карточка клиента (7 вкладок) — десктоп + мобильный
- Кабинет клиента: Сегодня, Дневник, Схемы, Практика, Профиль — десктоп + мобильный
- Вход, 2FA, Аккаунт, Подписка, Донат — десктоп + мобильный

## About the Design Files
Файлы в папке — **дизайн-референсы в HTML** (прототипы внешнего вида и поведения), а не продакшн-код. Задача — **воспроизвести их в существующем коде** `webapp/` (React + Vite, `index.css` с CSS-переменными, классы `.btn`, `.eyebrow`, `.section`, `.tabs` и т.д.), используя его паттерны. HTML открывается в браузере напрямую (рядом должен лежать `support.js`). Данные в прототипах — демонстрационные.

## Fidelity
**High-fidelity.** Цвета, шрифты, радиусы, отступы — финальные. Воспроизводить точно, через токены (см. Design Tokens), а не инлайн-хексами.

### Листы и оверлеи кабинета (#746)
Макетов на эти экраны в хэндоффе нет: каждый лист переведён на уже построенную систему («тот же экран, та же логика, та же структура блоков — новая оболочка»). Общие примитивы — `styles/cabinet.css` (`ds-*`), у каждой зоны свой css с префиксом (`styles/sheet-tracker.css` `tk2-`, `sheet-schemas.css` `ss-`, `sheet-settings.css` `st-`, `sheet-exercises.css` `ex2-`, `sheet-diary.css` `sd-`, `sheet-tasks.css` `sk-`, `sheet-modemap.css` `mm2-`), цвет сущностей — hue из `lib/tone.ts`. Тумблер темы из настроек убран (решение владельца 2026-10-16): кабинет только светлый, `applyCabinetLightTheme()` в `AppShell` не пишет в `localStorage`, поэтому выбор на лендинге сохраняется. Тумблер `role="switch"` — один `.ds-switch` (аккаунт и настройки).

Отступления, которые стоит знать:
- **Трекер**: своя шкала `PickerRail` (кнопки 0–10) заменена общим `NeedScale` (1–10 с маркером «вчера»), как в «Сегодня» и `NeedTodaySheet`. Нуля на шкале больше нет; сохранение нуля и раньше пропускалось (`useRatingSaver` не пишет 0), так что данные не меняются.
- **Планы** (`PlansScreen`): над списком добавлена полоса доли завершённых планов — считается из тех же данных, в исходном экране её не было.
- **Кризисная карточка**: `webapp/src/components/CrisisCard.tsx` — парный файл с мини-аппом (`check-paired-files`), поэтому не менялся; общая `CrisisCardView` из shared рисует себя токеном `--accent`, который в редизайне уже новый, и в кабинете смотрится как тонированная карточка с акцентной рамкой.

- **`Loader`** остался спиннером (класс `.spinner` пинят чужие тесты); правило «скелетоны по форме» для экранов выполняют существующие скелетоны.

## Interactions & Behavior
- Все тогглы/фильтры — мгновенные, без анимаций кроме hover (transform translateY(-1px/-2px) на цветных карточках, смена бордера на карточках, тоггл — `left .15s`).
- Адаптив: все многоколоночные сетки — `repeat(auto-fit, minmax(…, 1fr))`; правые сайдбары уходят вниз; имена/бейджи/кнопки `white-space: nowrap`, ряды — `flex-wrap`.
- Мобильный (<768): сайдбар → нижний таб-бар `#1F1B17` h76 (4 пункта у терапевта: Сегодня/Клиенты/Поиск/Профиль; 5 у клиента), активный — белый 700 + точка `#C8553D` над подписью. Вкладки карточки клиента — горизонтальный скролл. Главные действия карточки — закреплённая нижняя панель с двумя кнопками h48.
- Минимальная зона нажатия на мобильном — 44px.
- Состояния загрузки/ошибок — сохранить существующую логику (скелетоны по форме контента), перекрасить в новые токены.
