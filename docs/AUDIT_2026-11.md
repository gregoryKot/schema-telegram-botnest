# Аудит 2026-11: безопасность, баги, надёжность, путь клиента

Снимок — 2026-11-07, HEAD `main` `feed710`; правки — PR #1016.

Аудит по просьбе владельца с четырьмя целями по порядку: **1) безопасность,
2) работа без багов и ошибок, 3) логичность и надёжность продукта,
4) понятность и польза для клиента и его путь целиком.** Девять срезов прошли
параллельно, только чтение кода: вход и сессии, доступ к чужим данным (все
контроллеры), деньги, безопасность фронтенда, инфраструктура и данные, бот и
напоминания, доменная логика, баги сайта, путь клиента и психолога. Каждую
находку P0/P1 ведущий перепроверил по коду; известное из `docs/open/*`,
`docs/security/AUDIT_FINDINGS.md` и `SECURITY.md` §12–13 не повторяется, если
статус в документе верен.

Ответ в трёх фразах:

1. **Дыры уровня «любой берёт чужие данные» в коде не нашлось.** Все 50
   контроллеров проверены: каждая выборка идёт по `userId` из гарда, кабинет
   психолога везде зовёт `assertHasClient`, подписи и JWT держат инварианты.
   Но дамп боевой БД с данными 17 человек **на 2026-11-07 по-прежнему читается
   с GitHub анонимно** (D-1), а проба, которую документ называл существующей,
   в коде отсутствовала: система об этом молчала.
2. **Нашлись атаки «по ссылке» и «на общем компьютере».** Ссылка
   `/auth/callback#access_token=…` тихо сажала человека в аккаунт атакующего;
   кука «Привязать Telegram» переживала выход и отдавала аккаунт следующему,
   кто войдёт через Telegram; вебхук оплаты отражал HTML с нашего адреса;
   ответы API с дневниками оседали в дисковом кэше браузера. Всё это
   исправлено в этом PR.
3. **Для клиента продукт рвётся на стыках: человек без Telegram, полночь
   по Москве и возвращение после паузы.** Напоминания и приглашение психолога
   работают только через Telegram, в «Сегодня» и «Истории» вчерашний день
   до 03:00 пуст, после 15 минут в фоне первое сохранение падает (исправлено),
   «Мне очень плохо» вела к телефонам доверия за три касания (исправлено).

## 5. Путь клиента целиком

| Этап | Оценка |
|---|---|
| Первый заход (лендинг, мини-тесты, статьи) | Лендинг ясный; мини-тесты уводят в бота (U7), «диагностика» спорит с тестом (U9) |
| Вход | Google, VK, Telegram внятны; почта без помощи «не пришло» (U6) |
| Онбординг и «Сегодня» | Понятно: три плитки и «Зачем это»; задания психолога с главной не видны (U2) |
| Инструменты | Пустые состояния и пояснения есть; вчерашний день до 03:00 пуст (E5), «Пройти заново» пугает (U8), старые записи не открыть (R6) |
| Связь с психологом | Рвётся у человека без Telegram в трёх местах (U3, U4, U2) и на офлайн-карточке (S8) |
| Запись и оплата | Все исходы оплаты отработаны; длина брони теперь привязана к слоту (R1) |
| Аккаунт | Слияние, экспорт, удаление, выход написаны честно; слияние молча теряет конфликтующие записи (R3) |
| Кризисная поддержка | Тексты проверяются детекцией; вход к телефонам — одно касание (U1) |
| Возвращение | Напоминания — только Telegram (U5); после паузы вечером «Неделя без дневника» (R4); «Итоги дня» выключает не то (R2) |

**Три доработки пути с наибольшей пользой:**

1. **Связь с психологом без Telegram насквозь:** приглашение — ссылка на
   сайт с кодом в тексте; счётчик новых заданий на «Ещё»; кнопки уведомлений
   открывают задание или тест; «Терапевт рядом» всегда с действием (U2–U4).
2. **Напоминания не только в Telegram:** хотя бы честная развилка в планах
   и «Добавить в календарь» как основной путь, дальше — письмо или
   веб-уведомления (U5). Человек, вошедший через Google, почту или MAX, сейчас
   не получает ни одного напоминания вернуться.
3. **День — по местному времени везде:** «История», профиль, планы,
   напоминания в Америках и на Дальнем Востоке (E5, E11, E13).
