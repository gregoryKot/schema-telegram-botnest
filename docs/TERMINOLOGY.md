# Термины схема-терапии — единая русскоязычная терминология

**Главный эталон** — документ «Создание единой русскоязычной терминологии для
использования в программах обучения схема-терапии, научных исследованиях и
литературе, и клинической концептуализации» (Психологический центр Ассоциация
«АНИМА» — П. М. Касьяник; Московский институт схема-терапии — А. В. Ялтонская,
Н. В. Гегель, Д. А. Марьясова; Балтийский институт схема-терапии — Илона Кроне;
Наталья Дикова). Прислан владельцем 2026-09-28.

**Второй эталон** — сайт МИСТ ([schema-therapy.ru](https://schema-therapy.ru):
/schemes, /modes, /emotionalneeds). Берём оттуда только то, чего в документе
нет (новые схемы YSQ-R, виды Гиперконтролёра, Поллианна, потребности). Где
документ и сайт расходятся, прав документ.

Своих переводов у проекта нет. Буква «ё» (Отстранённый, Ребёнок) — орфография,
а не другой перевод. Названия режимов и групп режимов пишутся с заглавных, как
в документе: «Уязвимый Ребёнок», «Карающий Критик», «Режимы Сердитого Ребёнка».
Бытовое «внутренний критик», «внутренний ребёнок» — не название режима, его не
трогаем.

Механизм принуждения — `scripts/check-schema-terms.mjs` (CI, джоба `checks`):
варианты из столбцов «не писать» роняют CI. Правила — в
`scripts/schema-terms-rules.mjs`, тест гейта —
`src/test-support/gates/schema-terms.spec.ts`.

## Ранние дезадаптивные схемы

«Ранние дезадаптивные схемы» — не «неадаптивные» и не «дисфункциональные».

| Домен | Схема | Не писать (как название) |
|---|---|---|
| Разобщение / Отвержение | Эмоциональная депривированность | Эмоциональная депривация |
| | Покинутость / Нестабильность | Брошенность |
| | Недоверие / Ожидание жестокого обращения | Недоверие / Жестокое обращение, Недоверие / Насилие |
| | Социальная отчуждённость | Социальная изоляция |
| | Дефективность / Стыдливость | Дефективность / Стыд, Дефектность |
| Нарушенная автономия | Неуспешность | Неудача, Провал |
| | Зависимость / Беспомощность | Зависимость / Некомпетентность |
| | Уязвимость | Уязвимость к болезням и опасностям, Уязвимость к вреду |
| | Запутанность / Неразвитая идентичность | Спутанность, Слияние |
| Направленность на других | Покорность | Подчинение |
| | Самопожертвование | — |
| | Поиск одобрения | Поиск одобрения / Признания |
| Нарушенные границы | Привилегированность / Грандиозность | Грандиозность / Особые права |
| | Недостаточность самоконтроля | Недостаточный самоконтроль / Самодисциплина |
| Сверхбдительность и запреты | Негативизм / Пессимизм | — |
| | Подавленность эмоций | Подавление эмоций, Эмоциональная ингибиция, Эмоциональная сдержанность |
| | Жёсткие стандарты / Придирчивость | Непреклонные стандарты, Завышенные стандарты |
| | Пунитивность | Карательность, Наказуемость |

Схемы из YSQ-R, которых нет в документе (берём у МИСТ): Эмоциональная
скованность, Страх потери контроля над эмоциями, Пунитивность (направленная на
себя), Пунитивность (направленная на других). Продукт раскладывает их по
пятому домену — решение описано в шапке `schemaDomains.ts`.

Домены не называть: «Отчуждение и отвержение», «Разобщённость и отвержение»,
«Нарушение связи и отвержение», «Нарушение автономии и достижений»,
«Ориентация на других», «Бдительность и подавление», «Сверхбдительность и
подавление эмоций».

## Эмоциональные потребности

В документе их нет. По МИСТ — пять групп: надёжная привязанность; свободное
выражение чувств и потребностей; автономия, компетентность и чувство
идентичности; спонтанность и игра; реалистичные границы и самоконтроль.

## Режимы проявления схем

| Группа (как в документе) | Режим | Не писать |
|---|---|---|
| Здоровые и функциональные режимы: Счастливый детский режим, Здоровые Взрослые режимы | Счастливый Ребёнок, Здоровый Взрослый, Хороший Родитель | Добрый Родитель |
| Уязвимые детские режимы | Уязвимый, Одинокий, Покинутый (он же Подвергшийся Насилию), Униженный, Зависимый Ребёнок | — |
| Режимы Сердитого Ребёнка | Сердитый, Упрямый, Разъярённый Ребёнок | Злой Ребёнок, Злящийся Ребёнок |
| Режимы Импульсивного Ребёнка | Импульсивный, Недисциплинированный Ребёнок | — |
| Дисфункциональные режимы Критика (Родителя) | Требовательный Критик, Карающий (Наказывающий) Критик, Внушающий Вину Критик | Карающий/Требовательный/Наказывающий/Критикующий Родитель |
| Копинговые режимы капитуляции | Послушный Капитулянт, Беспомощный Капитулянт | Покорный Капитулянт, Уступчивый Капитулянт |
| Избегающие копинговые режимы | Отстранённый Защитник, Отстранённый Самоутешитель, Гневный Защитник, Избегающий Защитник | Самоуспокоитель |
| Гиперкомпенсаторные копинговые режимы | Самовозвеличиватель, Гиперконтролёр, Перфекционист, Подозрительный Гиперконтролёр, Агрессор, Манипулятор, Хищник, Ищущий Внимания и Одобрения | Перфекционист-Гиперконтролёр, Гиперкомпенсатор (такого режима нет — это группа) |

Режимы, которых нет в документе (берём у МИСТ): Неуязвимый, Самобичующий,
Компульсивный, Беспокоящийся Гиперконтролёр; Поллианна (не «Полианна»).

«Дисфункциональные родители» как название группы не пишем — только
«Дисфункциональные режимы Критика».

## Название метода

«Схема-терапия» — через дефис. Не «схематерапия» и не «схемотерапия».
