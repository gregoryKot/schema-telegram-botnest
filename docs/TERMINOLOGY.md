# Термины схема-терапии — сверка с МИСТ

Эталон — сайт Московского института схема-терапии
([schema-therapy.ru](https://schema-therapy.ru)): страницы
[/schemes](https://schema-therapy.ru/schemes),
[/modes](https://schema-therapy.ru/modes),
[/emotionalneeds](https://schema-therapy.ru/emotionalneeds). Сверено
2026-09-27. Своих переводов у проекта нет: если термин есть у МИСТ, пишем как
у МИСТ. Буква «ё» (Отстранённый, Ребёнок) — орфография, а не другой перевод.

Названия режимов пишутся с заглавных букв в обоих словах, как у МИСТ и в
реестре `shared/src/schemaTherapy/content/modeGroups.ts`: «Уязвимый Ребёнок»,
«Карающий Критик». Бытовое «внутренний критик», «внутренний ребёнок» — не
название режима, его не трогаем.

Механизм принуждения — `scripts/check-schema-terms.mjs` (CI, джоба `checks`):
запрещённые варианты из таблиц ниже роняют CI. Правило живёт в
`scripts/schema-terms-rules.mjs`, тест гейта —
`src/test-support/gates/schema-terms.spec.ts`.

## Ранние дезадаптивные схемы

«Ранние дезадаптивные схемы» — не «неадаптивные» и не «дисфункциональные».

| Домен (МИСТ) | Схема (МИСТ) | Не писать |
|---|---|---|
| Нарушение связи и отвержение | Эмоциональная депривация | — |
| | Покинутость / Нестабильность | Брошенность (как название схемы) |
| | Недоверие / Ожидание жестокого обращения | Недоверие / Жестокое обращение, Недоверие / Насилие |
| | Дефективность / Стыд | Дефектность |
| | Социальная отчуждённость | Социальная изоляция |
| Нарушенная автономия | Зависимость / Беспомощность | Зависимость / Некомпетентность |
| | Уязвимость | Уязвимость к болезням и опасностям, Уязвимость к вреду |
| | Спутанность / Неразвитая идентичность | Запутанность, Слияние |
| | Неуспешность | Неудача, Провал |
| Нарушенные границы | Привилегированность / Грандиозность | Грандиозность / Особые права |
| | Недостаточность самоконтроля | Недостаточный самоконтроль / Самодисциплина |
| Направленность на других | Покорность | Подчинение |
| | Самопожертвование | — |
| | Поиск одобрения | Поиск одобрения / Признания |
| Сверхбдительность и подавление эмоций | Негативизм / Пессимизм | — |
| | Подавление эмоций | Эмоциональная ингибиция, Эмоциональная сдержанность |
| | Жёсткие стандарты / Придирчивость | Непреклонные стандарты, Завышенные стандарты (как название схемы) |
| | Пунитивность | Карательность, Наказуемость |

Схемы из YSQ-R, которые МИСТ пока не распределил по доменам: Эмоциональная
скованность, Страх потери контроля над эмоциями, Пунитивность (направленная на
себя), Пунитивность (направленная на других). Продукт раскладывает их по
пятому домену — это решение описано в шапке `schemaDomains.ts`.

Домены не называть: «Разобщённость и отвержение», «Отчуждение и отвержение»,
«Нарушение автономии и достижений», «Ориентация на других», «Бдительность и
подавление».

## Эмоциональные потребности

Пять групп (МИСТ): надёжная привязанность; свободное выражение чувств и
потребностей; автономия, компетентность и чувство идентичности; спонтанность и
игра; реалистичные границы и самоконтроль.

## Режимы

Четыре группы: детские, критикующие (родительские), копинговые, здоровые.
Копинги: Капитуляция, Избегание, Гиперкомпенсация.

| Группа | Режим (МИСТ) | Не писать |
|---|---|---|
| Детские | Уязвимый, Одинокий, Покинутый, Униженный, Зависимый Ребёнок | — |
| | Сердитый, Упрямый, Разъярённый Ребёнок | Злой Ребёнок, Злящийся Ребёнок |
| | Импульсивный, Недисциплинированный Ребёнок | — |
| Критикующие | Требовательный Критик | Требовательный Родитель |
| | Карающий Критик | Карающий Родитель, Наказывающий Родитель/Критик, Критикующий Родитель |
| | Внушающий Вину Критик | — |
| Капитуляция | Послушный Капитулянт, Беспомощный Капитулянт | Покорный Капитулянт, Уступчивый Капитулянт |
| Избегание | Отстранённый Защитник, Отстранённый Самоутешитель, Избегающий Защитник, Гневный Защитник | Самоуспокоитель |
| Гиперкомпенсация | Самовозвеличиватель, Гиперконтролёр (и его виды), Агрессор, Манипулятор, Хищник, Ищущий Внимания и Одобрения, Поллианна | Гиперкомпенсатор (такого режима нет — это группа), Полианна |
| Здоровые | Счастливый Ребёнок, Здоровый Взрослый, Хороший Родитель | Добрый Родитель |

Группу критикующих режимов в текстах для людей называем «Критик» /
«критикующие режимы», а не «Дисфункциональные родители».

## Название метода

«Схема-терапия», «схема-терапевтический» — через дефис, как у МИСТ. Не
«схематерапия» и не «схемотерапия».
