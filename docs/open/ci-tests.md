**Мажоры зависимостей: решения владельца** (разбор бот-PR 2026-10-22; процедура доводки —
`audit-2026-10.md`, «Dependabot: доводка бот-PR»):
- **TypeScript 7 не берём** — `ignore` мажора `typescript` в `.github/dependabot.yml` для `/`,
  `/webapp`, `/shared` (#686 закрыт). TS 7 — нативный компилятор, а
  `typescript-eslint` 8.72 объявляет `typescript >=4.8.4 <6.1.0`, `ts-jest` 29.4 — `<7`. Вернуться,
  когда оба примут 7 (`npm view typescript-eslint peerDependencies`, `npm view ts-jest
  peerDependencies`): снять `ignore`, переезд одним PR во все пакеты (правило №3).
- **https-proxy-agent 8+ не берём** — `ignore` мажора в записи `/` (#534 закрыт). С 8-й версии
  пакет только ESM, бэкенд собран в CommonJS: jest падает на
  `src/telegram/telegram.providers.spec.ts` («Must use import to load ES Module»). Применение
  одно — `src/telegram/telegram-agent.ts`. Вернуться при переезде бэкенда на ESM.
- **Babel 8 не берём** (2026-11-08, разбор в #1027; бот-PR #892, #855, #856 закрыты) — `ignore`
  мажора `@babel/*` в записи `/`. Babel 8 только ESM (`"type": "module"`, Node ≥22.18): сам
  трансформер `src/test-support/esm-to-cjs.transform.cjs` под ним работает (babel-jest грузит
  ядро обычным `require(esm)` Node), но `src/test-support/esm-to-cjs.transform.spec.ts`
  импортирует `@babel/core` внутри jest и падает «Must use import to load ES Module». Пользы
  нет: Babel нужен только этому трансформеру, а на Node 24.9+ трансформер, его спек и три
  пакета `@babel/*` удаляются целиком. Вернуться тогда же — снять `ignore` вместе с Babel.
- **Логи прода после деплоя Nest 12 никто не смотрел.** Взятые мажоры (Nest 12 #845, Stryker 10 #842,
  Vitest 5 #844, jsdom 30 #846, `actions/github-script` 9 #522) проверены ночами: 11-07 и 11-08 зелёные
  целиком, мутации дошли до отчёта, `ci-alarm` на `github-script@v9` заводил issue (#992, #1017); формат
  HTTP-ошибок Nest 12.4 поправлен в #1027. Остались первые минуты прода после деплоя (остановка
  Express-адаптера) — логи Amvera агенту недоступны; косвенно держат `prod-smoke` и `crashesDay` в `/health`.
