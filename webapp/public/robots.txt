# Личный кабинет, вход, админка и мини-апп закрыты от индексации для ВСЕХ
# ботов. Блок Disallow повторён в каждой группе намеренно: бот, нашедший
# группу со своим именем, группу «*» не читает вовсе (RFC 9309 §2.2.1, так же
# у Яндекса) — одинокий «Allow: /» в такой группе открывал ему весь кабинет.
# Сверка с роутами webapp/src/App.tsx — webapp/src/robotsTxt.test.ts.
# «/app$» и «/app?» вместо «/app»: префикс задел бы /apple-touch-icon.png.
# /api/ НЕ закрыт намеренно: Googlebot и YandexBot рендерят SPA и соблюдают
# robots.txt для fetch — статьи (/api/articles) и мини-тесты (/api/quizzes)
# без API отрендерились бы пустыми. Закрытые ручки без входа отдают 401.
